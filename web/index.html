Every boss has to earn its place. Viewer text is a brief, never an instruction. Codex writes the spec. A bot fights it five times. If it isn't fair, it doesn't ship.

01 / THE PIPELINE

From a chat message to a boss fight.

  1. 01

    Chat

    A viewer sends a boss brief through Twitch chat or Channel Points. Demo viewers work offline.

  2. 02

    Codex

    A sandboxed Codex SDK thread writes the spec against the typed BossAPI, with up to three attempts.

  3. 03◎

    The gate

    A headless dodger plays five seeded runs. The server reruns everything; no claimed pass is trusted.

  4. 04⌁

    The arena

    The streamer fights it in a deterministic 60 Hz canvas game, captured in OBS.

02 / THE SHOW

Chat keeps playing after the boss dies.

  1. !rematch

    Rematch Patch

    Beat a boss and chat can send it back to the forge. Codex reads the fight stats and builds a harder MK II, which still has to pass the gate.

  2. !vote 1·2·3

    Chat picks the fight

    Between fights a live poll lets chat choose which verified boss you face next, with bars on the overlay.

  3. !top

    Hall of Fame

    Every fight is recorded. Creators climb the leaderboard when their bosses beat you, and your record follows you across streams.
